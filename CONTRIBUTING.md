# Contributing to Glasswing Power

Thank you for considering contributing to glasswing-power!

## Getting Started

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request

## Code Style

- Follow Rust's standard formatting (`cargo fmt`)
- Run `cargo clippy` to catch common issues
- Keep the codebase light and clean
